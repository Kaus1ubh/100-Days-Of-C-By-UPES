# 100 Days of Code — C Programming

My work for the **100 Days of Code in C** challenge set as part of the first-year
curriculum at **UPES Dehradun**.

Two problems a day for the first 50 days, one a day after that.

## Structure

```
Day N/
  QX (Topic).c
```

Every file opens with the question statement and its sample test cases as comments,
followed by the solution. All programs are plain C11 and compile clean under
`gcc -Wall -Wextra`.

```bash
gcc "Day 1/Q1 (User Inputs, Operations & Output).c" -o q1 && ./q1
```
